# P-GPT 粗精煤泥模型

入口：现有“粗精煤泥分析”页面的 P-GPT 按钮，或同一服务的 `/pgpt.html`。

## 实现边界

本版本从用户指定 Excel 独立建模，没有阅读 DS/GPT 的训练、按日聚合、选参、预测实现。只读取原页面 HTML 和通用 CSS/图表库以保持界面风格。原 `index.html` 仅新增 P-GPT 链接和返回导航脚本引用；其余功能在新文件中实现。没有改写已有 DS/GPT 模型、共享求解器、训练数据或本地存储。没有重建 `backend/data/train_js.json`。

`frontend/pgpt/model.js` 同时用于浏览器计算和 Node 离线构建，消除两份公式的偏差。`models.js` 保存两个模型的完整独立参数。当前版本使用源 Excel 的固定快照，**不自动同步原页面的导入数据**。浏览器重训练仅使用这份快照，模型在本次页面会话内生效，训练历史使用独立存储键。增加数据后须按下方命令重建快照与模型。

## 两个模型

目标为315灰分。输入九项：原煤灰分、小时带煤量、A/B/401/402系统开停、473/474脱粉开停、精磁尾液位。采样开停为0/1，日工况为平均开停比例。未使用同次化验的315全水分，避免依赖目标检测时才得到的信息。工作面作为溯源字段保留，第一版未作为模型因素。

两个粒度分别聚合、选参和训练，日模型不是采样预测的平均值。方法为带截距的标准化岭回归，优化目标为 `mean((y - b0 - Zb)^2) + lambda * sum(b^2)`，截距不惩罚。输入缺失值、均值、标准差仅由当前训练折计算；缺失值用训练中位数替代；常量列系数为0。预测不以目标灰分或测试数据做修正，不暗中截断异常输出。

候选正则参数在首次向前检验前固定为0.01、0.1、1、10、100。6—7月前半段作为初始训练，后半段分三块顺序验证，每折只使用更早生产日，同一日不跨训练和验证；按合并验证RMSE选参。两个模型均选中λ=1。调参验证用于选择参数，不能视为独立测试。
