# 主机统一存储，笔记本访问主机

- 当前主机服务：`http://10.255.2.7:8000/`。笔记本通过主机网页和 API 读取、补录，由主机写入本机 SQLite。
- 主机已有离线安装时使用专项 `ProjectUpdate.zip`，全部解压后，以原安装用户双击 `UpdateProject.cmd`。
- 专项更新核验原程序 SHA256，先备份主机 SQLite（含 WAL 中已提交数据）和源码，仅停止本安装的 Web 服务，保留采集运行。保留主机 `backend/data`、配置、证书、模型与 Python 环境；启动时自动追加新 schema。
- 更新失败回滚源码，不用旧数据库快照覆盖正在增长的生产数据。备份在主机安装目录 `backups/source-update-*`。
- 笔记本启用本地、被 Git 忽略的 `backend/data/client-mode.json`：`{"mode":"client","server_url":"http://10.255.2.7:8000/"}`。常规服务、采集及看门狗入口将停止启动独立数据链。
- 笔记本已有数据库保留为历史备份，不上传覆盖主机。切换前核对的 7 条本机补录均已存在于主机 19 条记录中。
- 开发测试继续使用隔离数据库。要恢复笔记本独立部署，需明确停用 client-mode 配置并重新决定数据源。
- 验收依据：主机健康、小时策略 v4、新界面名称、采集样本继续增长、笔记本没有本项目 Web/采集进程，且普通启动入口不会再次创建本机数据库服务。
