技术方案
一、项目概述
1.1 项目背景
重介选煤是选煤厂的核心工艺环节，分选密度的精准控制直接影响精煤产率和产品质量。东滩选煤厂的精煤产品由重介精煤、浮选精煤、粗精煤构成，产品构成复杂，精煤产品通过两条皮带机（501皮带和502皮带）运输，501皮带入料包含401、402系统重介精煤、浮精、粗精；502皮带入料包含A、B系统重介精煤。不同系统组合运行时，对在线灰分仪的测量结果有直接影响，精煤产品质量稳定控制的难度较大，直接影响产品质量和精煤回收率。
传统方式存在的问题：
响应滞后：指标变化后需要人工判断，响应时间长
精度不足：依赖个人经验，缺乏量化标准
缺乏追溯：历史调整记录难以追溯和分析
知识流失：老工人退休后经验难以传承
缺乏成熟可靠的数据分析系统：没有一套完整的数据分析体系来指导操作，难以通过精确的数据分析对重介密度进行调整，容易出现分选指标异常，造成精煤回收损失
1.2 系统目标
通过数据采集、智能分析、决策支持，实现重介分选密度的智能化监控和优化调整。
核心目标：
实时监控：采集原煤、产品的关键指标，区分501/502两条皮带的产品数据
智能分析：基于数学模型计算最优密度设定值，分别对401/402系统（对应501皮带）和A/B系统（对应502皮带）给出密度建议
决策支持：给出密度调整建议，辅助操作员决策
历史追溯：完整记录指标变化和调整建议
1.3 系统定位
数据分析与监控型决策支持系统
采集实时数据和人工录入数据
根据采集的精磁尾池液位、粗精煤泥灰分，基于数学回归模型计算不同精磁尾池液位对粗精煤泥灰分的影响，并进行累积计算
利用三种模型分别计算最优密度
给出密度调整建议（供参考）
记录历史数据和调整日志
不直接控制PLC系统

2.5.1 基础原理
重介分选密度与产品灰分之间存在稳定的函数关系。由于501皮带和502皮带的入料构成不同，需要分别建立密度预测模型。
模型1（用于401/402系统）：ρ密度_401/402 = f(原煤灰分, 501皮带总精煤灰分, 原煤煤量, 悬浮液煤泥含量, 浮精影响值, 粗精影响值)

2.5.3 总精煤灰分计算逻辑
场景1：使用在线灰分仪（实时控制）
501皮带总灰分 = 501灰分仪读数（已包含浮精、粗精影响）
502皮带总灰分 = 502灰分仪读数
场景2：使用人工化验数据（班次控制或灰分仪故障时）
501皮带总灰分 = 401/402重介精煤化验灰分 + 浮精影响值 + 粗精影响值
502皮带总灰分 = A/B重介精煤化验灰分
2.5.4 多元线性回归模型

2.5.3 模型训练流程
数据收集：收集近3-6个月历史生产数据，分别按501皮带和502皮带对应的系统整理
数据预处理：特征选择、异常值剔除、数据归一化，对于缺失数据采用插值方法处理
影响值计算：从历史数据中回归出浮精、粗精对总灰分的影响系数
模型拟合：使用最小二乘法求解回归系数
模型验证：用验证集评估模型精度（R²、RMSE）
模型部署：投入使用，采用离线计算与流式计算相结合的方式，离线计算调度批量任务处理大规模静态数据用于模型定期更新，流式计算保障算法模型实时在线运行
模型更新：定期更新（每月/季度），必要时利用近期数据触发按需更新，以适应工况变化

九、方案优化与补充
根据系统实际运行需求和技术发展，对本方案进行以下优化补充：
9.1 新增计算模型
为提高系统适应性和预测精度，在原有多元线性回归模型基础上，新增两套计算模型：
9.1.1 模型2：基于BP神经网络的非线性模型
【模型原理】
神经网络能够捕捉密度与灰分之间的非线性关系，特别适合处理复杂的工艺过程。
【网络结构】
• 输入层：9个特征（基础特征6个 + 衍生特征3个）
• 隐藏层1：12个神经元，ReLU激活函数
• 隐藏层2：8个神经元，ReLU激活函数
• 输出层：1个神经元，Linear激活函数
【特征工程】
• 基础特征：原煤灰分、精煤灰分偏差、煤泥含量、原煤煤量、磁性物含量、当前密度
• 衍生特征：灰分偏差平方、灰分-煤泥交互项、流量-灰分比值
• 历史特征：3个时间点的灰分趋势、密度趋势
【训练参数】
• 学习率：0.001
• 批次大小：32
• 训练轮数：100（含早停机制）
• Dropout率：0.2
• L2正则化：0.01
【在线学习】
支持增量学习，新数据到达时持续更新模型，缓冲区积累1000条数据后触发权重更新。
9.1.2 模型3：专家规则 + 自适应加权混合模型
【模型原理】
结合重介选煤理论公式和现场专家经验，通过自适应加权融合多种预测方法。
【理论计算模型】
• 基础公式：ρ = ρ₀ + k₁×(A原煤-A基准) + k₂×(A产品目标-A基准)
• 其中：ρ₀=1.50g/cm³，k₁=0.008，k₂=0.015
• 煤泥补偿：煤泥含量每增加1%，密度增加0.01
• 磁性物补偿：磁性物在250-350g/l范围内最佳
【专家规则库】
• 灰分超标紧急调整：灰分 &gt; 目标 + 0.5% → 密度降低0.03（优先级1-最高）
• 灰分偏低调整：灰分 &lt; 目标 - 0.3% → 密度提高0.02（优先级2）
• 煤泥含量高补偿：煤泥 &gt; 35% → 按比例增加密度（优先级3）
• 处理量变化补偿：流量变化 &gt; 50t/h → 微调密度±0.01（优先级4）
• 浮精卸料稳定：浮精卸料中 → 不调整（优先级1-最高）
【自适应加权融合】
• 初始权重：理论模型40%，专家规则30%，回归模型30%
• 动态调整：基于各方法预测误差自动调整权重
• 学习率：0.1（平滑更新）
• 窗口大小：20（基于最近20次预测）
9.2 三模型融合决策机制
【初始权重分配】
• 回归模型：25%（线性关系场景）
• 神经网络：35%（非线性关系场景）
• 混合模型：40%（理论+经验场景）
【动态调整机制】
1. 基于置信度调整：各模型预测置信度
2. 基于工况调整：稳定/变化/异常工况
3. 基于历史表现调整：各模型准确率
【模型选择决策树】
第一步：数据质量评估
• 质量 &lt; 0.6：使用混合模型（专家规则主导）
• 质量 0.6-0.8：使用回归模型
• 质量 &gt; 0.8：继续下一步判断
第二步：工况稳定性判断
• 稳定工况（&gt;0.8）：使用回归模型
• 变化工况（0.3-0.8）：使用神经网络
• 异常工况（&lt;0.3）：使用混合模型
第三步：模型一致性检查
• 预测一致（标准差 &lt; 0.02）：加权融合
• 预测分歧（0.02-0.05）：降低置信度
• 严重分歧（&gt; 0.05）：使用混合模型，降低置信度
9.3 数据质量评估模块
为提高数据可靠性，增加数据质量评估功能：
【评估维度】
• 完整性检查：数据缺失率评估
• 准确性检查：与历史数据对比验证
• 一致性检查：跨传感器数据验证
• 及时性检查：数据延迟监控
• 传感器健康度：故障预测和诊断
【质量评分】
• 综合评分（0-1分）：≥0.8优秀，0.6-0.8良好，&lt;0.6不合格
• 不合格数据自动标记，不参与模型计算
9.4 模型性能监控与自动切换
【性能指标】
• MAE：平均绝对误差
• RMSE：均方根误差
• 准确率：±0.02范围内的比例
• 偏差：系统性高估或低估
【切换条件】
• 最大MAE阈值：0.03
• 最小准确率阈值：85%
• 最大性能漂移：0.02
【切换策略】
• 基于性能：当某模型明显优于当前模型时切换
• 基于一致性：当模型预测严重分歧时使用混合模型
• 手动覆盖：操作员可手动选择模型
9.5 验收标准补充
【模型性能指标】
• 密度预测准确率（±0.02）：≥85%
• 密度预测准确率（±0.03）：≥95%
• 模型平均绝对误差（MAE）：≤0.025 g/cm³
• 模型决定系数（R²）：≥0.80
【系统性能指标】
• 建议合理率（人工评估）：≥75%
• 模型切换响应时间：&lt;5秒
• 数据质量评估准确率：≥95%
