# 决策总览

在顶部菜单打开“决策总览”。原“密度推荐总览”和其他页面保留。也可以在系统地址后加 `#decision` 直接进入新页。

页面以建议密度为中心，左侧展示重介精煤、浮精，右侧展示粗精煤泥；外层为灰分、煤量、系统状态、脱粉状态、液位等因素。箭头指向被计算或被解释的对象。卡片默认显示当前业务值；选取采集点后，普通卡片改为显示所选点的采集值、来源与接收时刻。中间建议密度保留计算值，所选点显示为“采集对照”。

2026-10-06 按用户要求移除画布中的“停机 / 低负荷”卡片及连线，右侧粗精煤泥量、原煤煤泥含量上移，画布为 18 个节点、17 条连线；该卡片的旧采集显示绑定在读取浏览器设置时忽略。底层模型的 `is_stoppage` 输入定义与计算保持原状。

最新布局见 [移除卡片后的画布](verification/remove-stoppage-20261006/decision-no-stoppage.png)与[验收记录](verification/remove-stoppage-20261006/result.json)：四档窗口无卡片重叠或溢出，三个状态组合仍正常展示，旧绑定被忽略，业务 store 不变。此页后文较早截图保留为对应改动时的验收记录。

左侧卡片的详情在右侧打开，右侧卡片的详情在左侧打开，中央“建议密度”的详情在下方打开。位置随画布缩放、滚动和窗口尺寸调整，不遮住所选卡片；窄屏侧边空间不足时改为下方。下方空间不足时适度滚动画布，极矮窗口则使用画布下方的详情区域。面板内容较多时可在面板内滚动。

支持深浅色切换、放大缩小和适应画布。点击画布空白处、点击“收起”或按 Escape 关闭详情；点击节点会查看对应详情，点击详情内容、采集点选择框或工具栏不会误关面板。面板中的按钮可进入相关业务页面。所选卡片滚出可见画布或切换页面时自动收起浮动详情。页面显示期间约每五秒更新只读快照，选择采集点时短暂延后刷新以保护操作。

默认使用蓝白纸张主题，点击“深色视图”可切换。页尾为独立的蓝色背景层：继续向下滚动时，前面的纸张层向上移出，逐渐露出背景与说明文字。背景高度随窗口调整；仅背景图层做轻微滚动位移，详情弹窗仍按窗口定位。这个主题只在“决策总览”启用，切到其他业务页面恢复原有样式。

蓝色背景叠加向下流动的波纹与细小光线，文字保持静止。动效使用独立 Canvas 2D 绘制，最高约 30 帧/秒，画布最长边限制为 1440 个绘制像素；不读取采集点、模型或业务 store。背景完全被纸张层遮住时停止绘制，露出后从暂停位置继续；切页、浏览器隐藏、打印及系统减少动态效果时也停止。Canvas 不可用时继续显示本地 SVG 背景。

配色和分层方式参考 [Nous Research 官网](https://nousresearch.com/)，纸张纹理和蓝色曲线为本项目原创的本地 SVG（`frontend/assets/decision-paper.svg`、`frontend/assets/decision-field.svg`）。没有使用官网图片、字体、脚本或远程画布资源，可在内网及离线环境显示。此前公开来源核查未找到明确覆盖其官网背景素材的复用许可，因此本次独立实现。

有效计算连线叠加沿箭头方向流动的光段，对应卡片显示轻微边框呼吸效果；选中链路更醒目，卡片位置和数值文字保持稳定。采集显示卡片相关连线改为虚线对照，因为显示映射没有改变模型输入。对照、待接入以及缺少数值的连线保持静态。动效仅示意计算方向，不代表 KEPServer 正在实时更新。

工具栏“暂停动效 / 开启动效”控制装饰动画，开关仅在当前页面内存中保留。切换页面或浏览器页面隐藏时暂停动画；系统开启“减少动态效果”时使用静态视图，打印时也保留静态箭头与数值。

暂停动效或系统开启“减少动态效果”时，蓝色背景图层停止流动、位移与淡入；滚动仍可查看页尾。打印时不显示装饰背景层。

## 数值与连线含义

- 中心为现有计算链的本步建议密度。数据不足或等待新化验时显示“—”及原因，不把当前密度冒充有效建议。
- 实线表示当前计算链，虚线表示核算对照或待接入的关系。人工总灰分被选中时，三组分属于核算对照；重介版或三组分公式来源下才进入相应建议计算。
- 默认查看 GPT 输入与原始预测。中心建议及粗精组分值仍按当前生产模型计算。查看 GPT 不会切换或训练模型；没有保存的 GPT 模型时显示“未训练”。人工覆盖粗精灰分时，模型因素连线改为对照。
- 质量占比、加权灰分贡献用于说明三组分质量平衡，不是密度因果影响或模型准确率。缺失值保留为空，默认值明确标注为非实时测量。
- 原图中的药剂量、原煤煤泥含量，目前缺少对应的业务字段和模型关系，保留为待补充因素。

## 采集来源与时间

详情面板的“选择卡片显示点位”会立即更新该卡片；后台采集查询完成后自动更新显示，不另开一套 API 轮询。选择以来源和点 key 标识，保存在当前浏览器、当前站点的独立 localStorage 项中，切页、刷新和重载后保留；本地存储不可用时仅保留当前页面内存选择。“不使用采集值”清除映射并恢复原业务显示。

0 和布尔 false 都是合法采集值；布尔显示 0/1。只有当前可用的数值或布尔读数显示在卡片主值中。查询失败、坏质量、过期、离线或点位暂未返回时，主值显示“—”与不可用状态，保留选择等待恢复，详情仍可核对最后读数。采集点没有单位时不沿用卡片原有单位，悬停和详情明确提示单位未提供。

卡片显示映射不写入 App.store，不修改 GPT / DS 模型输入或生产计算。详情将采集显示值与原业务计算值分开列出；建议密度不会被现场实际密度覆盖。实际密度点建议选在“当前分选密度”卡片上。Good 质量仍需同时满足时效等可用性规则。

“系统运行状态”可选“四系统运行状态（组合）”，一个点位同时显示四路开关。现场确认映射为 478→401、479→402、A345→A、A346→B。组合保留四路各自状态，不做 OR / AND；详情显示原始标签和各路时间。旧的单路系统绑定在采集刷新后自动改为同来源的四系统组合。

“脱粉系统状态”可选“脱粉系统运行状态（组合）”，同时显示 473、474 两路开关。对应 `TIA_3_3.TIA_3_3.473/if_prod` 与 `TIA_3_3.TIA_3_3.474/if_prod`，保留各自状态，不做 OR / AND。以前在该卡片选择的 473 或 474 单路点位，会在采集刷新后自动迁移为同来源脱粉组合；其他点位选择及“不使用采集值”保持不变。

“浮精压滤机运行”可选“浮精压滤机运行状态（组合）”，以两行两列分别显示 A415、A416、A417、A418 四台的开关状态。数据来自 `TIA_4_2.TIA_4_2.A415/YL_STATE` 至 `A418/YL_STATE` 的布尔运行信号；每台的 `PLATE_CNT` 仍为独立板数点，不用于推断运行。以前在该卡片选择的四台单路运行点会自动迁移为同来源压滤机组合，板数及其他点位选择保持不变。详情显示各台原始标签、状态和时间；组合展示不推导浮精产量，也不改变原密度计算。

这三个组合点由只读查询生成，放在接口 `derived_items` 中；停用 501A、502A 后原 `items` 为 50 个物理点，另有 3 个组合点。SQLite 简表也不增加伪造的 KEP 标签。每个组合的所有成员均有效、类型为布尔且接收时间一致时整体可用；缺失、坏质量、离线、过期或不同批次时组合不可用，异常成员显示“未知”，其余有效成员仍可核对。全部为关仍是有效数据。组合时间来自真实成员，不使用查询时刻替代。没有新增组合历史，不能用分钟历史声称完整记录了每次开关切换。

业务记录、人工输入、模型预测、默认值与实时采集分别标注。历史记录没有化验出报告时间，页面不会根据采样时刻推定结果已可用。未知时间显示“未记录”，未来时间提示核对。
