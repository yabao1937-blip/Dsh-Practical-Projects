# 决策总览

在顶部菜单打开“决策总览”。原“密度推荐总览”和其他页面保留。也可以在系统地址后加 `#decision` 直接进入新页。

页面以建议密度为中心，左侧展示重介精煤、浮精，右侧展示粗精煤泥；外层为灰分、煤量、系统状态、脱粉状态、液位等因素。箭头指向被计算或被解释的对象。节点显示当前业务值及来源，点击后在详情面板查看取值口径、记录时间、人工录入时间和采集来源。

左侧卡片的详情在右侧打开，右侧卡片的详情在左侧打开，中央“建议密度”的详情在下方打开。位置随画布缩放、滚动和窗口尺寸调整，不遮住所选卡片；窄屏侧边空间不足时改为下方。下方空间不足时适度滚动画布，极矮窗口则使用画布下方的详情区域。面板内容较多时可在面板内滚动。

支持深浅色切换、放大缩小和适应画布。点击画布空白处、点击“收起”或按 Escape 关闭详情；点击节点会查看对应详情，点击详情内容、采集点选择框或工具栏不会误关面板。面板中的按钮可进入相关业务页面。所选卡片滚出可见画布或切换页面时自动收起浮动详情。页面显示期间约每五秒更新只读快照，选择采集点时短暂延后刷新以保护操作。

默认使用蓝白纸张主题，点击“深色视图”可切换。页尾为独立的蓝色背景层：继续向下滚动时，前面的纸张层向上移出，逐渐露出背景与说明文字。背景高度随窗口调整；仅背景图层做轻微滚动位移，详情弹窗仍按窗口定位。这个主题只在“决策总览”启用，切到其他业务页面恢复原有样式。

蓝色背景叠加向下流动的波纹与细小光线，文字保持静止。动效使用独立 Canvas 2D 绘制，最高约 30 帧/秒，画布最长边限制为 1440 个绘制像素；不读取采集点、模型或业务 store。背景完全被纸张层遮住时停止绘制，露出后从暂停位置继续；切页、浏览器隐藏、打印及系统减少动态效果时也停止。Canvas 不可用时继续显示本地 SVG 背景。

配色和分层方式参考 [Nous Research 官网](https://nousresearch.com/)，纸张纹理和蓝色曲线为本项目原创的本地 SVG（`frontend/assets/decision-paper.svg`、`frontend/assets/decision-field.svg`）。没有使用官网图片、字体、脚本或远程画布资源，可在内网及离线环境显示。此前公开来源核查未找到明确覆盖其官网背景素材的复用许可，因此本次独立实现。

有效计算连线叠加沿箭头方向流动的光段，对应卡片显示轻微边框呼吸效果；选中链路更醒目，卡片位置和数值文字保持稳定。对照、待接入以及缺少数值的连线保持静态。动效仅示意计算方向，不代表 KEPServer 正在实时更新。

工具栏“暂停动效 / 开启动效”控制装饰动画，开关仅在当前页面内存中保留。切换页面或浏览器页面隐藏时暂停动画；系统开启“减少动态效果”时使用静态视图，打印时也保留静态箭头与数值。

暂停动效或系统开启“减少动态效果”时，蓝色背景图层停止流动、位移与淡入；滚动仍可查看页尾。打印时不显示装饰背景层。

## 数值与连线含义

- 中心为现有计算链的本步建议密度。数据不足或等待新化验时显示“—”及原因，不把当前密度冒充有效建议。
- 实线表示当前计算链，虚线表示核算对照或待接入的关系。人工总灰分被选中时，三组分属于核算对照；重介版或三组分公式来源下才进入相应建议计算。
- 默认查看 GPT 输入与原始预测。中心建议及粗精组分值仍按当前生产模型计算。查看 GPT 不会切换或训练模型；没有保存的 GPT 模型时显示“未训练”。人工覆盖粗精灰分时，模型因素连线改为对照。
- 质量占比、加权灰分贡献用于说明三组分质量平衡，不是密度因果影响或模型准确率。缺失值保留为空，默认值明确标注为非实时测量。
- 原图中的药剂量、原煤煤泥含量，目前缺少对应的业务字段和模型关系，保留为待补充因素。

## 采集来源与时间

详情面板的“查看采集点”只用于核对 KEPServer 来源、最后读数、质量、源时间、服务器时间和接收时间。选择保留在当前页面内存中，不保存映射，不使采集值进入模型或密度建议。采集查询失败时最后读数显示为不可用；Good 质量仍需同时满足时效等可用性规则。

业务记录、人工输入、模型预测、默认值与实时采集分别标注。历史记录没有化验出报告时间，页面不会根据采样时刻推定结果已可用。未知时间显示“未记录”，未来时间提示核对。

## 维护与验证

页面入口在 `frontend/index.html`，新页面逻辑与样式独立放在 `frontend/js/decision-overview.js` 和 `frontend/css/decision-overview.css`。`app.js` 只增加导航、刷新及直达入口；DS 训练、预测、日级聚合、选参、保存模型及对拍基线未改动。

背景绘制独立放在 `frontend/js/decision-background.js`；`DecisionOverviewPage` 只负责可见性与动效开关，不参与绘制算法。

现有读取函数带自动打点和 EMA 保存副作用，因此新页在私有 store 副本上执行已有取值方法，并关闭保存。同一时间戳复用保存的 EMA，不在浏览页面时推进共享平滑状态。

只读回归：`node backend/scripts/verify_decision_overview.js`。浏览器验收脚本 `backend/scripts/verify_decision_overview_browser.js` 使用独立 Chrome 上下文和 `file://`，不连接服务器数据库；需要可用的 Playwright 库，可用 `DMCS_PLAYWRIGHT_MODULE` 指定现有库路径。验收记录位于 [browser-result.json](verification/decision-overview-20261005/browser-result.json)，覆盖四档宽度、节点详情、主题、缩放、页面切换和采集参考。
