# 小时推测简报

新页面替换原“三表 1h 对齐”页面。旧离线计算器保留用于兼容和原版对拍，页面与导入入口均不再调用它。

## 生成与保存

- 后端服务启动时启用任务，从下一北京时间整点开始，每小时一行。首次启用前的小时不补生成。
- 关闭浏览器不影响任务；需要后端服务持续运行。每个整点是唯一主键，多进程或重复执行不产生重复行。
- 每行冻结输入、来源、采样/接收时间、默认及沿用标记、模型参数、计算结果和建议理由。后续补录和模型切换不改写已保存行。
- 服务中断错过的整点保留缺失行，注明未完成快照，不用当前配置回算过去。允许任务在整点后 90 秒内完成，以整点为取数截止时间。
- 新表 hourly_brief_schedule、hourly_brief_rows 不属于旧 /state 整库镜像。
- 新迁移 0006 接续工作区现有业务补录迁移 0005。当前现场库原来使用启动自动建表且未登记 Alembic 版本；此次也通过既有启动机制建立新表，未盲目 stamp 旧库。直接在此类旧库执行全量 alembic upgrade head 会因旧表已存在失败，应先独立核对旧库基线。

## 取数口径

KEP 记录必须在整点前已接收、质量有效、配置定义一致且未超时。手工补录同时要求采样时间及录入时间不晚于整点，按采样时间取最近记录；不把后录入的历史化验当成当时已知。

默认值和沿用值均明确标注。模型十因素缺任一项时不以均值补全；未配置的展示项（例如药剂量）不会额外阻断其他计算。停机因子沿用既有口径：有效原始入洗量 ≤10 t/h 为 1，否则为 0。

总灰分要求三组分灰分、煤量完整有效且总量大于零。建议以该小时的有效密度为基准，取消模拟阶段固定的 1.350–1.600 上下限；保留单步上限（默认 0.02）、专家完整修正上限 0.03、容差及动作保持规则。停机沿用值参与快照推测时保留标记，不能据此将停机期间累计为实际产量。

2026-10-08 10 点后按用户最新确认启用 `hour-boundary-v2`：1.000 不再视为 A303/A304 的有效业务密度。原始 KEP 读数及质量码仍原样保存在 `telemetry_points.latest` 和 `telemetry_readings`；业务用值单独放在 `effective_density`，持久化分路记忆在 `_display_memory.last_density`。回退按来源、点位定义和单位隔离，跨整点另保留该时刻的分路有效记忆，防止后续新值和历史清理影响整点取值。旧浏览器整体均值缓存不参与新规则。

已经生成的 v1 小时行保持原快照，不随新规则重算。此前正常显示实际 1.000、超出固定范围不出建议的规则仅适用于这些历史行。旧离线简报算法及 DS 训练对拍基线不变。

单位显示沿用项目其他页面已经确认的同一指标定义。A303/A304 的实际密度、设定密度及平均密度在点位单位为空时，复用在线仪表及密度总览的 `g/cm³`，用于卡片、详情和采集表；明确配置的单位优先。此为显示信息补全，不修改原始样本、点位定义或历史有效值记忆。

## 实际密度与设定密度告警

- A303、A304 分别将原始 `MD` 与本路 `MD_SET` 比较，`abs(实际 − 设定) > 0.3` 时触发，等于阈值不触发。正常有效新读数进入范围后自动解除。
- 告警不采用业务回退值。比如 A303 实际 1.000、设定 1.480，即使显示层能沿用历史密度，仍按偏差 0.480 告警。A304 实际 1.477、设定 1.480 的偏差 0.003 正常。
- 只比较同来源、同批次、同单位、质量及时间有效且配置唯一的两点。断线、坏质量、缺数或配置歧义标为“无法判断”；网页保留已知异常并显示“待确认”，不当作恢复。
- `/telemetry/latest` 返回 `density_alarm_checks`，不改写原始记录或旧告警表。现有顶部告警数量合并灰分与密度告警；点击、回车或空格可展开详情，打开的详情随每 5 秒轮询刷新。密度告警与业务存储独立，不触发保存或预测。

为保证真正取到整点前最近一次 5 秒读数，采集跨整点覆盖 latest 前会额外留存前一条原始快照；普通分钟历史和原值保持原口径。
