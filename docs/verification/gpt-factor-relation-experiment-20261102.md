# 三系统粗精灰分：固定四模型历史关系试验

2026-11-02。本轮已按预先锁定协议完成一次固定矩阵，未增加候选、调参或反复选模型。结果尚不足以支持把瞬时液位或煤量加入后得到稳定的 ±1 灰分百分点预测：21 条逐日历史回放中，训练中位数常数 M0 命中 **9/21=42.9%**、MAE **1.300**；自由液位、煤量、液位＋煤量模型命中为 **8—9/21**，MAE **1.354—1.462**，未稳定优于常数参考。常规样本 80% 的目标未达到。

全历史常规训练分组内，液位每升 10 个百分点对应灰分约下降 **0.28—0.30 个百分点**，明显小于原经验的下降 3.00；这只是已有同一三系统组合的历史关系描述，不能直接当作新的生产规律。早期滚动训练的液位系数还会随候选和日期变号，负荷系数随日期亦不稳定。未选出“最佳物理滞后”，未替换旧 GPT/EXPERT8 或生产 90 秒配置。
