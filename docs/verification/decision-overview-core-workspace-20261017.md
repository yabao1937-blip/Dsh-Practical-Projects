# 第四批：决策总览界面与维护收拢

2026-10-17，仅实施于笔记本 `readonly-test`。服务为 `http://127.0.0.1:8000/`，数据来自主机 `10.255.2.7:8000` 的认证只读通道。主机未部署；未写生产数据库、配置或采集；卡片坐标、大小、连线和已确认计算口径不变。

## 最终行为

- 测试服默认进入决策总览；导航只保留「决策总览 / 系统维护」。七个原页面均保留，集中在维护页；可查看点位配置、业务备份恢复和复用运行快照的诊断。完整数据库备份仍使用原主机脚本，没有新增定时备份任务。
- 补录由 `ManualMeasurementComponent` 独立挂载：采集页与总览浮窗各有自己的 DOM，共享草稿、分页和幂等保存状态；不再移动采集页面板，也没有两份表单模板。实际生产时间、同小时取最新采样和粗精煤泥灰分仅归档口径不变。
- 核心页读取 `GET /api/v1/readonly-runtime/bootstrap`：主机时间、版本、九项设置白名单及完整 sources；不读取 AutoState、模型分析或历史大表。原 `/state` 和模型接口保留给显式打开的历史/旧分析页面，生产与 DS 原读法不变。
- 历史图表折叠，展开才读取完整历史和模型；模型轮询、实时结果观察、主题切换也遵守该条件。目标范围查看复用轻量 bootstrap，避免隐式触发旧全量 startup。
- 初始化期间点击导航会保留；完整历史请求按浏览器合并，旧请求完成不会抢回已切走的页面。延迟 bootstrap 不清空先完成的历史；历史加载/刷新失败不隐藏已正常工作的核心页，并明确提示保留的历史状态。
- 测试服补录、目标修改和模型保存仍受只读限制。目标范围只禁用输入及应用，取消始终可用。
