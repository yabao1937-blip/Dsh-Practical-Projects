# 密度趋势：小时建议实线与无建议小时红线回落 · 2026-10-28

## 需求（用户 2026-10-28）

1. 小时建议曲线改为**实线**连接（原橙色虚线圆点）。
2. 小时建议无法给出（缺失必要计算数据）的小时，用**红线**显示，数值默认回落为
   **当时的设定密度**（该小时 A304 锚点值）。原「缺失留空断线」口径由本指令局部取代。

## 实现（仅前端，端点数据语义不变）

- `frontend/js/decision-density-trend.js`：
  - `adviceWithFallback()`：对每个有 A304 锚点的小时——已有 null 值建议行（被闸住/
    不同基准）则就地回落为锚点值并标记 `missing`；整小时无建议行则按锚点合成一个
    回落点；两者 `basis.channels` 统一为 `['A304']` 以保持相邻小时连线。无锚点小时的
    null 行保留断线语义（无设定密度可回落，诚实留空）。
  - 绘制：建议曲线去掉 `[6,4]` 虚线改实线（线宽 3 不变）；逐段着色——任一端为
    `missing` 的线段用 `--trend-advice-missing` 红，有效建议段保持橙色；回落小时
    画红点（`showPoint` 对 missing 恒真）。
  - 悬停：回落点显示「本小时建议无法给出（缺失必要计算数据）· 红线回落为当时设定
    密度 X · 适用小时 …」，有存档原因（如灰分覆盖不足）时附原因。
  - 数值标注与「放大建议时段」仍只跟随**真实**建议（排除回落点）；差值阴影跟随实际
    所画曲线（回落段与设定相同处不产生阴影）。
- `frontend/css/decision-density-trend.css`：新增 `--trend-advice-missing`（深色
  `#e05252` / 浅色 `#c23434`）；建议图例色块改实线。
- `frontend/index.html`：图例新增「无建议小时（红线＝当时设定密度）」，css/js 版本
  号 v=1→v=2。（修复过程：一次 PowerShell 重写曾把 index.html 按 GBK 误写为乱码，
  已从 git 恢复并用 UTF-8 安全工具重做，服务端实测页面恢复中文正常。）
