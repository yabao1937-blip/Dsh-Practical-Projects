## 优先级与可执行验证

1. **P1：先验证灰分版本和质量。** 将“当时依据值、生产小时、生成/发布时间、暂估状态、后续修订”并列回放，重点复查上述两次跨8.5阈值及凌晨大幅目标。再提出暂估分级、方向稳定条件或人工复核的候选规则。验收应同时报告各类建议覆盖、方向翻转、错误暂缓及全样本表现；不得按预测误差删样，也不能用最终修订值回写当时先验。
2. **P2：分开评估参考目标与实际执行。** 离线同时列出小时固定基准、参考目标、当前设定及单步限幅。对7个远端目标检查来源质量、建议存续与后续修订；是否增加质量相关的目标保护，需要单独设计和验证。本次不改基准、死区、增益或执行限制。
3. **P3：补足可评价的成组响应记录，再讨论增益与等待时间。** 保留严格组和约1分钟记录组，动作所在小时剔除，下一动作后的小时标记混杂；以后同时记录产量、煤源/系统、停机、总灰分各组分及实际密度稳定过程。先观察0…4小时完整时段，收集足够非暂估、无相邻动作且工况稳定事件，再拟定离线候选验证。这里不从少量相关事件拟合“最佳时滞”，不声称未执行建议一定更好。

观察灰分是产煤量加权的总灰分，包含暂估/组分口径，并非只由A304单独决定；20条动作详情只能证明观测区间两端开关组合未变，不能排除小时内煤量、煤质、实际密度和其他工况变化。已查看数据属于历史诊断回放，不是新的独立盲测。
