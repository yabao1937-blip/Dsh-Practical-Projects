# 液位与粗精煤泥灰分：无约束模型与经验对比

日期：2026-10-31。已完成笔记本离线实验；未激活新模型、未部署主机、未改生产数据库。分析程序只读取已冻结的本地审计文件。

## 结论

这批三系统样本没有复现经验直线的强负相关。经验设定是液位每增加10个百分点，灰分降低3个百分点；普通自由直线对应增加0.029个百分点，稳健自由直线对应降低0.386个百分点。

这不能推出“液位没有影响”。普通拟合的斜率会被一条31.42%的化验明显拉动；数据还包含日期、负荷、采样和工况变化。当前证据支持重新审视固定斜率−0.3，不支持立即把生产模型换成一条近乎水平的线，也不能把残差直接解释为不同煤质。

普通自由拟合的历史拟合误差变小，但按日期向前验证没有优于冻结GPT。预先设定的稳健版本在开发期验证较好；最后时间段的严格样本仅3条，它和旧GPT基本打平。因此保留生产模型，本轮结果作为进一步验证的候选依据。

## 比较了什么

无约束指截距、斜率方向和幅度均自由，不做液位裁剪、输出裁剪或±2修正限制；并不等于任意增加模型复杂度。本次没有搜索多项式阶数、滞后时间、特征窗口或超参数。

- 经验直线：`灰分 = 30.5 − 0.3 × 液位`；另算25—75%截断版本。
- 冻结GPT：现用EXPERT8完整预测，包括其他因子的既有修正。
- 开发集均值：检验拟合液位是否比只报一个常数更有价值。
- 固定斜率、只调截距：区分整体偏移与液位敏感度的差异。
- 普通自由液位直线：预先指定的主候选。
- 自由液位＋入洗量：检查负荷混杂；没有给恒定开关强行拟合系数。
- 稳健自由液位直线：Huber损失，固定阈值1.5灰分百分点，无参数边界；全部样本仍进入训练。

三系统严格开发集中，A、473、474均关，B、401、402均开。能辨识的是液位和入洗量关联，不是八个独立因素的贡献。

## 主组三系统结果

下表均为**日期等权MAE，单位为灰分百分点**。拟合列不可当作预测准确率。

| 模型 | 开发拟合：31条／12天 | 开发向前验证：18条／8天 | 时间尾段：3条／2天 |
|---|---:|---:|---:|
| 开发集均值 | 2.331 | 2.308 | 1.110 |
| 经验直线 | 3.757 | 2.813 | 1.642 |
| 冻结GPT | 3.521 | 2.446 | 1.310 |
| 固定斜率、仅调截距 | 3.287 | 2.180 | 1.050 |
| 普通自由液位直线 | 2.343 | 2.768 | 1.128 |
| 自由液位＋入洗量 | 2.327 | 2.390 | 1.158 |
| 稳健自由液位直线 | 1.938 | 1.557 | 1.296 |

经验截断曲线与原经验直线在三系统的结果完全相同。严格开发样本液位26.30—74.57%、入洗量499.93—666.05 t/h，均未触发旧GPT边界；三系统近似及尾段也未越界。因此，输入截断不能解释本组三系统的偏差。总体审计中液位低于25、入洗量低于416的样本全部属于两系统。

三系统开发集拟合公式（L为液位%，Q为入洗量t/h；Y为灰分%）：

```text
普通自由直线：Y = 12.30715 + 0.00290677 × (L − 50)
稳健自由直线：Y = 11.73552 − 0.03859731 × (L − 50)
固定经验斜率：Y = 28.71345 − 0.3 × L
液位加负荷：  Y = 9.70342 + 0.01063487 × (L − 50) + 2.30346 × ((Q − 500) / 100)
```

公式是离线候选，不是已启用的生产参数，也不应外推到未覆盖的开机组合和液位范围。

## 差异来自哪里

### 1. 旧经验的液位敏感度在这批数据上偏强

旧GPT的−0.3是代码中的固定经验斜率，不是本批数据库样本自由拟合得到的结论；其余因子只在经验线外提供有界修正（±2个百分点）。所以仅重训原结构的其他系数，不能重新学习液位敏感度，也难以解释31.42%这类高值。

例如经验直线在液位30%时给21.5%灰分；本次普通自由直线约12.25%、稳健直线约12.51%。散点并没有沿着原经验的陡降方向排列。只调整截距能减小整体偏差，但不能证明斜率−0.3仍然适用。

这只是当前样本的关联结果。没有稳定工况下的成对控制试验，不能据此判断设备的因果响应，更不能反过来建议现场人为调液位以达到某个灰分。

### 2. 一条高值能改变普通拟合的斜率方向

| 处理（均仅开发数据） | 液位斜率：灰分百分点／液位百分点 |
|---|---:|
| 全部31条，普通拟合 | +0.00291 |
| 每个日期等总拟合权重 | −0.02258 |
| Huber稳健拟合 | −0.03860 |
| 仅作诊断，去掉ID63的31.42% | −0.04167 |
| 控制入洗量后的液位项 | +0.01063 |
| 同日期内去均值后的液位关系 | +0.00423 |

31.42%对应10月18日22:40:31，匹配液位66.72%。6分13秒后的下一条化验为12.02%，匹配液位41.96%；液位和灰分都大幅变化。该高值可能涉及真实工况突变、取样代表性或记录问题，现有资料不能裁定原因。主分析保留它，没有自动删点。

按日期整组重抽样2000次，自由斜率的2.5%—97.5%分位范围约为−0.0774至+0.0884，横跨零；逐日留一也会改变符号。这是12天小样本下的探索性稳定性诊断，不是精确的因果置信区间。

稳健模型降低了这一高值对常规拟合的影响，但对真实高灰分突变仍可能预测不足；不能把“常规误差更小”等同于解释了异常工况。

### 3. 入洗量和日期差异没有恢复强负液位关系

加入入洗量后，液位项为+0.01063；同日期内斜率为+0.00423，同时控制同日期内负荷后为+0.00509。不同日期均值之间的斜率约−0.05129。不能据此说日期就是煤质；也不能将入洗量的回归系数直接解释为因果效应。

自由模型加负荷后开发验证有改善，但尾段3条全部低估，平均偏差约−1.16个百分点。这进一步说明，仅凭31条开发样本拟合新的多因子公式还不稳定。

### 4. 分钟近似样本没有改变主要判断

加入7条近似开发样本后，普通斜率为−0.01640，稳健斜率为−0.04847；仍明显弱于−0.3。在相同18条严格验证行上，普通自由模型日期等权MAE为2.757，稳健模型为1.585，旧GPT仍为2.446。

严格与近似测试行分别存档。近似数据是离线敏感性检查，不代表这些数据满足当时实时有效性规则。

## 后续建议

1. 继续收集新的前瞻样本，用同一套已冻结候选比较；本次尾段不再作为“新的独立测试”。覆盖不同液位、负荷和开机组合，并记录实际取样时刻、取样是瞬时还是混合样、出报告时刻和修改记录。
2. 优先核对31.42%这类突变的原始化验和采样过程，核实前不改原值。结合采样前后的液位变化判断是否为稳定工况。
3. 本次保持用户确认的90秒滞后；尚未验证别的时延或平均窗口。若下一轮要研究动态延迟，先固定候选窗口，再用新数据验证，不能在本次尾段上反复试到最优。
4. 稳健弱斜率模型值得作为后续对照，暂不激活。若要辨识煤质差异，先证明在同等工况下存在可重复的分组差异，而不是按一次残差贴煤质标签。
