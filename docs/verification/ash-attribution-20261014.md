# 重介化验归属小时修订验证（2026-10-14）

## 最新口径

- 10:00–10:59 采样的重介精煤灰分对应 08:00–09:00；非整点按采样所在小时确定归属。00点采样对应前一天22–23点。
- 目标小时在结束后一小时开始展示。例如10:45最新为08–09，而11点起最新为09–10。
- 对应化验未补录时，用已知的最近前序重介化验暂估；若独立补录表没有记录，则保留原逐次有效总灰分作为暂估。悬停标识暂估，补录后可更新，没有旧版固定截止冻结。
- 只采用查询时已录入且采样时间不在未来的记录；后续生产小时的化验不反向用于更早小时。同归属窗口多条记录继续按均值使用。
- 用原时段的粗精预测、浮精、煤量与501+502实际产量权重计算；不重跑模型，不更改原始逐次、冻结小时、密度建议或实际采样时间。原时段无有效明细时不凭化验造数据。

## 实现与缓存

`gpt-ash-settlement-v2` 使用原表 `gpt_ash_settlements` 保存可更新缓存；`deadline` 兼容列改指发布时间，不是后续补录截止。修订签名只含实际选用的化验、策略版本和原小时证据版本。

读接口在一致的只读快照中检查签名，过期时返回新计算，不写数据库。后台每次最多回算两个小时，重计算在读事务中完成，短写事务复核新化验与证据，避免旧准备结果覆盖新结果。轮转检查历史缓存，不在每个5秒周期解析所有小时明细。

补录成功后右表和已打开区间窗口重读。覆盖连续两次保存及查询进行中保存的刷新竞态；保留未查询日期编辑，不改变布局。
