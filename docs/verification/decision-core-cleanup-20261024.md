## 实现边界

- 删除六个旧页面控制器、XLSX 浏览器库、专属 DOM/CSS、旧 App UI 写入方法及对应过时验证脚本。
- 默认首页统一为决策总览。笔记本维护入口剩余 KEP、粗精分析、浮精分析；打开 KEP 不触发完整历史数据下载。
- KEP 主表只显示测点名称、实时值、状态、采样时间。名称包含设备编号，同名时补充配置设备分组；底层保留 `source_id + point_key`，ITEMID 等可通过悬停核对。
- 设备/标签/说明/ITEMID 本就主要集中在点位配置，并非历史表中的四个重复列。本轮不迁移数据库、不删除历史记录。原始采样 JSON 的版本化字典压缩另行设计。
- 撤销七组旧接口：overview、records、inputs、manual-entries、import、migrate、hourly-brief。保留 state、training、samples、manual-measurements、telemetry 与核心决策接口。
- 核心 `decision_hourly.worker` 独立管理生命周期，旧简报定时写入任务删除；关停仍等待在途任务结束。
- `hourly_brief.inputs/columns/models` 属共享取数/数据库兼容代码，保留。旧简报快照参考实现移到 `tests/legacy_hourly_reference.py`，应用不再加载，仅供隔离回归对照。
- DS 求解器、特征、保存模型与 `train_js.json` 未更改；基线 SHA256 为 `aa09b7a4574ec19be5f840b68f3611394b0584f2ec435b0abd062416f8566bbd`。
