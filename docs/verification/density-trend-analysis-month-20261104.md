## 建议的验证顺序

1. **先固定可评价证据。** 回算与默认实时档案分开；保存真实生成、写入及送达状态，保留每次revision的生产小时与暂估标记。先验比较不越过missing、不回填已知结局。候选规则若将来实施，应能在上述7条污染案例上明确拒绝当时先验。
2. **同时评价低灰与超灰。** 用目标带偏差、持续时长及覆盖分层统计，不将灰分越低等同越好。收集产率/原煤变化后，才讨论经济取舍；以新时间段检验，不能把本月已看数据再叫盲测。
3. **以成组动作验证幅度与停止条件。** 常规±0.010可作现场行为参照，1–4小时内反向记录作复盘清单；联看实际密度是否稳定、煤量/煤质/系统变化及操作者目的，再设计最小可逆试验。现有样本不能直接给出统一步长或固定等待小时数。
4. **再验证暂估风险如何传递给远端目标。** 例如11-04凌晨最终参考目标最低1.432、小时固定基准1.520；这仍是暂估依据下的参考目标，不能等同单步会降0.088，当前单步限幅与参考目标是两件事。候选质量分级或方向稳定条件应同时报告常规/全样本、错误追调及错误暂缓，不按预测误差删样。
